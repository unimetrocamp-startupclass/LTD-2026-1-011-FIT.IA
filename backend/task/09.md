# Refatoração de Use Case

Este documento descreve as diretrizes e requisitos para a refatoração do `src\usecases\GetHome.ts`, com foco em melhorias arquiteturais e de performance, mantendo a regra de negócio e o `OutputDto` final inalterados.

## Requisitos de Refatoração

A refatoração deve seguir rigorosamente as regras do projeto descritas nos seguintes documentos em `.codex`:

- `.codex\rules\architecture.md`
- `.codex\rules\typescript.md`
- `.codex\rules\general.md`

## Problemas Obrigatórios a Corrigir

### Overfetch Grave no Prisma

- Está trazendo `sessions` dentro de `workoutDays` sem necessidade.
- Está buscando sessões múltiplas vezes.

### Cálculo de Consistência Semanal Ineficiente

- `filter` dentro do loop (`7 * N`).
- Deve pré-agrupar sessões por data em `O(n)`.

### Cálculo de Streak Extremamente Caro

- Busca histórico inteiro do usuário.
- Deve limitar a busca para no máximo 365 dias anteriores à data atual.

### Uso Incorreto de Datas

- Uso de `day(0)` dependente de `locale`.
- Deve usar `startOf("week")` corretamente em UTC.

### Busca do Treino do Dia Está O(n)

- Criar um `Map<WeekDay, WorkoutDay>` para acesso `O(1)`.

### Melhorar Legibilidade e Separação Lógica Dentro do Mesmo Use Case

Criar funções privadas puras para:

- montar mapa de dias da semana
- agrupar sessões por data
- calcular consistência
- calcular streak

## Padrões Obrigatórios de Melhoria (seguir exatamente)

### Evitar `filter` no loop

Em vez de:

```typescript
for (let i = 0; i < 7; i++) {
  const daySessions = weekSessions.filter(...)
}
```

Fazer:

```typescript
const sessionsByDate = new Map<string, Session[]>();

for (const s of weekSessions) {
  const key = dayjs.utc(s.startedAt).format("YYYY-MM-DD");
  if (!sessionsByDate.has(key)) sessionsByDate.set(key, []);
  sessionsByDate.get(key)!.push(s);
}
```

### Evitar Overfetch

Em vez de:

```typescript
include: {
  workoutDays: {
    include: { exercises: true, sessions: true }
  }
}
```

Fazer:

```typescript
select: {
  id: true,
  workoutDays: {
    select: {
      id: true,
      name: true,
      weekDay: true,
      isRest: true,
      estimatedDurationInSeconds: true,
      coverImageUrl: true,
      exercises: { select: { id: true } }
    }
  }
}
```

### Limitar Busca da Streak

Em vez de buscar todas as sessões:

```typescript
completedAt: {
  not: null;
}
```

Fazer:

```typescript
startedAt: {
  gte: dayjs.utc(currentDate).subtract(365, "day").toDate();
}
```
